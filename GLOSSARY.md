# Skating Program Planning

Vocabulary for technical program planning under a selected competition profile.

## Language

**Jump element**:
A solo jump, jump combination or jump sequence occupying one jump-element place in a program.

**Same-direction connection**:
A connection whose listed jumps all rotate in the same direction. The direction can be clockwise or counterclockwise.

**Mixed-direction connection**:
A connection containing listed jumps that rotate in different directions.
_Avoid_: Illegal connection

**Planning preference**:
A personal restriction on proposed program content, separate from competition-rule eligibility.
_Avoid_: Competition rule
