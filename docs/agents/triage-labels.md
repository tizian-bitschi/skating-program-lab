# Triage labels

Engineering skills use these five canonical roles. Apply the corresponding
GitHub label from this table.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for autonomous implementation. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be implemented. |

When a skill refers to a triage role, use its GitHub label from this table.

Edit the GitHub label column if the repository adopts different names.
